# concise-output: make an update easier to read

[All skill examples](../../EXAMPLES.md)

[concise-output](../../.agents/skills/productivity/concise-output/SKILL.md) makes
updates easier to read while preserving the facts and outstanding work.

## Why use it

Get clearer drafts without repeating your writing preferences in every prompt.
The skill puts the main point first and removes repetition while preserving
requirements and uncertainty that readers need.

## Example prompt

```text
Use <concise-output> to rewrite this update so a teammate can quickly understand it:
At this point in time, the implementation of invoice downloads has been
completed. Before we can proceed with the release, it is necessary for us
to carry out a check that confirms only the owner can download an invoice.
```

## Illustrative result
```text
Invoice downloads are implemented. Before release, verify that only the invoice owner can download one.
```
