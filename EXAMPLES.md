# Skill examples

[Back to the README](README.md)

Find a skill by the problem it solves. Each linked example explains why the
skill is worth using, then shows a prompt and an illustrative result.
Setup is assumed.

## Write and communicate

| Need | Skill and example | Benefit |
| --- | --- | --- |
| Make an update easier to read | [concise-output](docs/examples/concise-output.md) | Keeps the facts and remaining work clear without repetition. |
| Summarize staged changes | [commit-message](docs/examples/commit-message.md) | Produces a copy-ready message without including unrelated edits. |
| Explain a change to reviewers | [pr-description](docs/examples/pr-description.md) | Connects the user problem, delivered behavior, and validation. |

## Investigate and plan

| Need | Skill and example | Benefit |
| --- | --- | --- |
| Decide whether an approach is viable | [quick-plan](docs/examples/quick-plan.md) | Investigates the blocking unknowns and gives one recommendation. |
| Turn a ticket into scoped work | [ticket-to-plan](docs/examples/ticket-to-plan.md) | Defines implementation units and validation based on repository evidence. |

## Review and validate

| Need | Skill and example | Benefit |
| --- | --- | --- |
| Review your branch or a teammate's PR | [review-branch](docs/examples/review-branch.md) | Finds actionable issues in any committed branch, with evidence and fixes. |
| Know what to check manually | [test-cases](docs/examples/test-cases.md) | Produces prioritized cases with concrete setup, actions, and expected results. |

These examples cover a selection of skills. See the [full catalog](README.md#skill-catalog)
for the rest, or [skill combinations and development workflows](docs/usage/workflows.md)
to understand how they fit together.
