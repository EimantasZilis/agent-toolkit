# Concise output

Lead with the decision, finding, or requested artifact. State each fact once,
keep the default to one or two sentences per point, and retain uncertainty when
it changes what the reader should do. Use headings or lists only when they make
the result easier to scan.

## Working rules

- Put the answer in the opening sentence or two.
- Prefer concrete verbs and plain language over throat-clearing.
- Explain a caveat when it affects safety, scope, or confidence; omit ceremony.
- For documents, give each section one job and do not add a duplicate summary.
- For reviews, lead with findings and include strengths only when they affect the decision.

## Final pass

Check that the first sentence answers the ask, no sentence merely repeats an
earlier one, and the reader can act without reconstructing the conclusion.
Expand when the request is explicitly educational or when compression would hide
an important branch or safety condition.
